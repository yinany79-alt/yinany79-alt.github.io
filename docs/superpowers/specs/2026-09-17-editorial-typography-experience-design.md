# 个人技术网站编辑型排版与经历模块设计

日期：2026-09-17

## 背景

当前网站已经完成中文信息架构、技术工作台首页、交互拓扑、项目与文章内容模型以及浅色/星球双主题，但项目目录、项目详情和文章页面仍存在标题过大、阅读层级偏“技术海报”、字体气质不够成熟的问题。首页尾部只简略呈现学校，工作经历没有形成独立内容模块，也没有使用京东与北京大学的品牌 Logo。

本轮目标是把网站从“展示型技术页面”进一步调整为可以长期维护的个人技术出版物：视觉参考 Claude/Anthropic 的克制、温暖和编辑感，但不复制其品牌素材，也不分发未经许可的商业字体文件。

## 视觉方向

采用“Claude/Anthropic 式编辑排版”。英文、数字和短标题使用接近传统书籍排版气质的系统衬线字体栈：`Iowan Old Style`、`Charter`、`Baskerville`，中文标题使用 `Songti SC`、`STSong`、`Noto Serif CJK SC` 等宋体栈。正文继续采用 `PingFang SC`、`Noto Sans CJK SC`、`Microsoft YaHei` 等现代无衬线字体，避免长篇中文全部使用宋体造成疲劳。

不下载、不打包 Anthropic 的专有字体。设计借鉴的是字体角色、字号关系、留白和内容层级，而不是对品牌视觉进行一比一复制。

整体色彩从冷灰技术界面调整为略带暖意的纸张色：浅色主题使用暖白背景、墨黑正文、陶土橙与低饱和蓝作为点缀；星球模式保留深色背景，并同步提供等价的文字、边界和强调色对比度。技术拓扑仍保留蓝色发光语汇，使首页的交互识别度不被编辑型排版削弱。

## 全站字体与尺寸系统

新增三类明确的字体角色：

1. `--font-editorial`：姓名、页面主标题、文章标题与项目标题。
2. `--font-sans`：正文、摘要、导航、经历描述和控件。
3. `--font-mono`：日期、编号、标签、技术状态与阅读时间。

页面主标题不再以占满首屏为目标。桌面内容页标题控制在约 40–52px，文章详情根据标题长度在约 38–54px 内自适应；移动端控制在约 30–38px。项目列表标题约 22–30px，文章列表标题约 20–28px。正文阅读列控制在约 680–760px，正文 16–17px，行高约 1.85–2.0。

首页姓名仍是首屏视觉中心，但不继续增大；它使用编辑型衬线栈，并与工作身份、欢迎语和机会状态形成紧凑组合。

## 项目目录与详情

项目目录继续复用结构化项目数据，但列表从“大标题记录行”改为更紧凑的编辑型目录。每条项目至少包含编号、项目类别、标题、摘要、职责、一个关键结果和标签；标题不超过两行，摘要和证据使用较小字号与更稳定的行距。

项目详情页的首屏改为紧凑两段式：上方是项目类别、标题与摘要，下方是职责、周期和标签。关键结果条带降低高度，不再与标题竞争。正文中的二级标题和三级标题统一缩小，段前间距用于体现章节，不依赖巨大字号制造层级。

## 文章目录与详情

文章目录采用日常博客/出版物结构：日期、栏目、文章标题、摘要、标签和阅读时间。标签筛选继续保留，但样式从工具面板感调整为轻量索引。文章标题使用编辑型字体，摘要与元信息使用无衬线和等宽字体形成对比。

文章详情页采用居中的窄阅读列：

- 主标题缩小并限制最大宽度；
- 日期、阅读时间与标签形成一条轻量元信息行；
- 正文段落、列表、引用、代码块和行内代码建立统一排版规则；
- 二级标题约 28–34px，三级标题约 21–24px；
- 长英文技术词允许自然换行，移动端不得产生横向滚动；
- 每篇文章继续生成独立页面元数据。

## 经历数据与组件

在结构化站点配置中新增经历数据，而不是把公司和学校写死在多个页面。每条经历包含：类型、组织、部门或院系、角色或专业、时间、补充信息、Logo 路径和 Logo 替代文本。

新增可复用的 `ExperienceList` 或等价组件：桌面端两列或两行紧凑卡片，移动端单列。Logo 使用固定视觉框，采用 `object-fit: contain`，不裁剪、不改变品牌颜色；文字仍是主要信息通道，Logo 不承担唯一识别作用。

经历组件将用于：

- 首页底部：替换现有“教育经历 / 个人资料 / GitHub”三格中的教育单格，并加入工作经历；简历和 GitHub 入口作为相邻行动区保留。
- 关于页：替换现有只包含教育经历的卡片，独立呈现工作与教育。
- 简历页：在能力方向卡片之后展示完整工作与教育经历，并保留 PDF 下载入口。

从现有简历目录复制以下本地资产到网站 `public/brands/`：

- 京东 Logo：源自现有简历 `logos/jd.png`。

## 交互与可访问性

- 固定导航、主题开关、标签筛选和拓扑节点交互继续保留。
- 字体调整不能降低正文和小号元信息的颜色对比度。
- 所有 Logo 均有替代文本；组织名称同时以可选择文本呈现。
- 标题层级保持每页单个 `h1`，主要区块使用 `h2`，文章内部按 `h2/h3` 递进。
- 320px、375px、768px 与桌面宽度下不得出现横向滚动。
- 200% 文本缩放后项目标题、经历信息和标签允许增高，不裁切。
- `prefers-reduced-motion` 下继续关闭持续动画和非必要转场。

## 实施边界

本轮修改内容结构、排版、经历组件与品牌资产，不重写现有项目和文章正文，不修改简历 PDF 内容，不增加未确认的联系方式、教育荣誉或工作指标。技术拓扑的数据与交互逻辑保持不变，只允许做与新字体系统一致的视觉微调。

## 验收标准

1. 首页、项目目录、三个项目详情、文章目录、三篇文章详情、简历页和关于页均使用统一编辑型字体系统。
2. 内容页标题较当前版本明显缩小，文章正文在桌面与移动端均适合连续阅读。
3. 京东和北京大学经历在首页、关于页和简历页出现，事实与时间一致，Logo 清晰且不变形。
4. 浅色和星球主题均通过视觉检查；小号文字保持可读。
5. 标签筛选、主题切换、拓扑节点、简历下载和站内链接没有回归。
6. 内容校验、ESLint、TypeScript、生产构建和全部静态路由产物校验通过。
7. 桌面、375px 移动端、星球模式和无横向溢出完成浏览器回归。
